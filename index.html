Sobre mí

Desarrollo web con IA como herramienta de todos los días.

Tengo 26 años y soy de La Plata. Antes de programar pasé seis años manejando las redes de un vivero, así que sé qué tiene que decir la web de un negocio y qué busca la gente cuando entra.

Hoy programo con IA al lado: Claude Code y Antigravity me ayudan a escribir, revisar y corregir código más rápido. La IA acelera, pero las decisiones de diseño, el contenido y el control de calidad los hago yo.

Por eso los tiempos son cortos: cada proyecto que ves acá lo entregué en 7 a 14 días.

Habilidades

Las herramientas con las que construyo cada proyecto.

  1. 01 / 06

    HTML & CSS

    La estructura y el estilo de toda página web: HTML define el contenido y CSS cómo se ve. Maqueto sitios semánticos, accesibles y responsive, con animaciones que suman sin hacerlos pesados.

  2. 02 / 06

    JavaScript

    El lenguaje que le da vida a la web y hace que la página responda a lo que hacés. Lo uso para interacciones, formularios, lógica del lado del cliente y scripts que automatizan tareas repetitivas.

  3. 03 / 06

    React

    Una librería para construir interfaces con componentes reutilizables. Armo aplicaciones de una sola página con estado dinámico, fáciles de mantener y de hacer crecer.

  4. 04 / 06

    Bases de Datos

    Donde vive la información de una aplicación: usuarios, pedidos, contenido. Conecto sitios con bases de datos para que guarden y muestren datos reales, no solo páginas estáticas.

  5. 05 / 06

    Herramientas IA

    Claude Code y Antigravity son parte de mi día a día: los uso para escribir, revisar y depurar código, y así entrego en 7 a 14 días sin resignar calidad.

  6. 06 / 06

    Redes Sociales

    Los canales donde una marca se encuentra con su público. Gestiono contenido y comunidades, y pienso la estrategia digital para que el sitio y las redes trabajen juntos.
